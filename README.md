# HAB-SD-Card-Data-Logging-System
This code's purpose is to create a logging system that will record more volatile data in an HAB scenario. 
The modlues that I used are the following: 

- MPU 6500: Gyroscope and Accelerometer data
- Ultimate Adafruit GPS Breakout Board: GPS location data
- Temperature Sensor DS18B20: Temperature data
- BME280: Pressure and humidity sensor
- HiLetgo SD Card Module: Stores data

- Credit:

This project was heavily adapted from a High Altitude Balloon data logger originally created by Christopher Lum. You can find the original repository here: [https://github.com/clum].
